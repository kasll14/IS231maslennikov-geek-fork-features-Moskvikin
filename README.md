Продукт: Проектирование и разработка веб-сайта для ИС «Компьютерные курсы»

PEST-анализ: 
  ---------------------------------------------------------
1 Политические факторы: Нацпроект «Цифровая экономика»
  ---------------------------------------------------------
  Возможность: Подача заявки на грант «Цифровые технологии» финансирование разработки, доступ к инфраструктуре
  ---------------------------------------------------------
  Угроза: Жёсткие требования к отчётности, риск изменения приоритетов финансирования
  ---------------------------------------------------------
2 Экономические факторы: 68% россиян готовы учиться новому для смены профессии (NAFI, 2024)
  ---------------------------------------------------------
  Возможность:Разработка B2B-продукта: корпоративные пакеты для переобучения сотрудников стабильный доход
  ---------------------------------------------------------
  Угроза:Экономия компаний на обучении в кризис откладывание закупок, ужесточение требований к ROI
  ---------------------------------------------------------
3 Социальные факторы: 58% пользователей из регионов ищут онлайн-альтернативы очному обучению (RAEC, 2024)
  ---------------------------------------------------------
  Возможность: Оптимизация под слабый интернет: офлайн-режим, лёгкие видео охват аудитории за пределами мегаполисов
  ---------------------------------------------------------
  Угроза: Логистические сложности поддержки: разные часовые пояса, языковые особенности
  ---------------------------------------------------------
4 Технологические факторы: AI-инструменты снижают затраты на проверку заданий на 40% (исследование SberAI, 2024)
  ---------------------------------------------------------
  Возможность: Внедрение AI-ассистента для подсказок и адаптивных траекторий рост вовлечённости и NPS
  ---------------------------------------------------------
  Угроза: Необходимость в квалифицированных кадрах для настройки ML-моделей, этические вопросы сбора данных
